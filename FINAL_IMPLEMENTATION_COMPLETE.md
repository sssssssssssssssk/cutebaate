## 🚀 **HOW TO USE EACH FEATURE**

### **Message Reactions**
- Long-press any message
- Select emoji from picker
- Reactions appear below message

### **Voice Messages**
- Click microphone icon 🎤
- Start speaking
- Click again to stop & send

### **Stickers & GIFs**
- Click smiley icon 😀
- Choose Stickers or GIFs tab
- Search or browse
- Click to send

### **Reply to Messages**
- Swipe message left (mobile)
- Or long-press → Reply
- Reply context shows at bottom
- Send your reply

### **Pin Messages**
- Long-press message
- Select "Pin"
- Pinned messages show at top

### **Self-Destruct**
- Long-press message
- Select timer (5s, 10s, 30s, 1m, 5m)
- Countdown shows on message
- Auto-deletes when timer expires

### **Search Messages**
- Click search icon 🔍
- Type your query
- Messages filter in real-time

### **Set Nickname**
- Click avatar icon 👤
- Enter nickname (max 20 chars)
- Shows next to your name
- Session-only (not stored)

### **Camera Photos**
- Click camera icon 📷
- Take photo
- Auto-uploads to chat

### **Dark Mode**
- Go to Settings
- Select Light/Dark/Auto
- Entire app switches instantly

### **Change Language**
- Go to Settings
- Select from 8 languages
- UI translates immediately

### **Upgrade to Premium**
- Go to Settings
- Click "Upgrade Now"
- See premium features unlock
